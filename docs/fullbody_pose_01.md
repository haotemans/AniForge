# 全身 01 · 标准正面站姿（轻度 A-Pose）— 通用设计参考

![全身 01 正面参考图](images/fullbody_01_pose_reference.webp)

> **参考图只用于确认姿势与构图**，不是 MMD / VPD 动作文件，也不是通过 AniForge 实际 Blender 渲染获得的模型样本。图中角色的外形、裙装、鞋子、发型、材质和装饰只是示意；插件不能围绕这一个角色定制姿势，也不能擅自改变其他模型的服装。

## 01 定稿方向

| 项目 | 设计规范 |
| --- | --- |
| 分组与序号 | **全身 / 01**；全身组规划为 **4 张标准四视图 + 8 张特色动作 = 12 张** |
| Pose | **正面自然站立 + 轻度 A-Pose**，双臂自然垂向两侧并与躯干留少量间隙 |
| 肩 / 手臂 | 双肩放松、不耸肩；双臂略向外展开，避免手掌和袖子紧贴腰部或挡住腰饰 |
| 手掌 | 手腕放松、手指自然弯曲；不握拳、不强制展开手指 |
| 躯干 / 头 | 身体自然直立、重心均衡；头部中正、看向正前方，不扭腰、不夸张歪头 |
| 腿脚 | 双腿自然伸直或微松弛，脚与髋近似同宽；双脚完整落地，不踮脚、不交叉腿 |
| 表情 | **自然中性**，双眼自然睁开，嘴部放松 |
| 相机 | **正面 0°、平视、俯仰 0°、滚转 0°**；标准四视图优先推荐正交相机以减少比例变化 |
| 构图比例 | **2:3 竖幅** |
| 背景 | **纯白 #FFFFFF**，无道具、无文字、无额外人物 |
| 取景 | **从最高头饰到最低鞋底全部入镜**；同时保留发梢、尾巴、裙摆、披风及两侧手指的安全留白 |
| 输出 | 仅为全身组 01 的独立标准正面图，不额外增加重复镜像 |

## 通用 MMD 模型设计与兼容原则

1. **不绑定特定骨架：** 依据模型肩、肘、腕、髋、膝、踝等骨骼及其相对长度设置自然正面姿态；兼容不同游戏的骨骼映射，并允许不能自动识别的模型手动校正。
2. **四视图基准一致：** 未来 01–04 分别覆盖正面 0°、左侧 90°、右侧 -90° 与正后 180°。四张使用**同一自然站姿、同一光照、同一背景和一致的人物尺度**，只改变相机方位，避免每张改变角色姿势而无法对比服装结构。
3. **优先完整展示服装：** 对大裙摆、翅膀、武器挂件、尾巴、超长发、宽大袖子以及高头饰，依据最终模型的实际边界动态计算相机尺度/距离，四视图在可行时保持共同尺度；不得裁切鞋子或关键装饰。
4. **轻度 A-Pose 而不是僵硬 T-Pose：** 让手臂远离腰侧以减少遮挡，但不能抬成水平直臂，不强行拉伸裙袖或肩部装饰；必要时允许调整抬臂角度与手掌位置。
5. **真实角色外观不做改动：** 保留衣服原始材质、发型、鞋靴、饰品、身体比例及贴图；不同角色应展示各自原本的视觉特征，而不是模仿参考图。
6. **质量检查与回退：** 在真正实现时，检查手掌/衣袖与躯干碰撞、发丝与肩饰穿模、裙装和鞋底是否被裁切；目前这些是设计目标，不宣称已具备全自动修复。
7. **光照与白底一致：** 采用相对均匀的拍摄光照，确保暗色衣服仍有细节，避免背景污染、强烈彩色环境反射和遮挡性投影。

## 与全身特色动作的分工

全身 **01–04** 首先记录角色原始比例、服装和鞋靴的**四向基准结构**；后续 **05–12** 再逐张设计腿部、重心、步态、转身和动态姿势，避免八张只有手势变化。其他镜头尚未定稿。

## 本 PR 的实施边界

**本次只增加设计文档和经用户确认的单张全身白底参考图。** 不修改现有 Blender 插件的全身出图数量、拍摄编排、骨架动作、相机实现或模型加载行为。全身 12 张是讨论中的目标方案，后续统一落地并使用不同 MMD 模型进行验证。
