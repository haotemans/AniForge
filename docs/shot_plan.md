# AniForge 36 张拍摄编排

由 `python tools/export_shot_plan.py` 从插件当前编排生成。正式输出四组各九张，每个位置只拍一张；不为每个 Pose 重复三视图。

每张先应用姿势、表情和头部/手型，再根据变形后的模型定位镜头。角度相对角色正面；默认 3:4 竖幅透视。

包含站姿、端坐和侧坐；全身两张坐姿、半身一张坐姿。衣服先在独立后台进程中稳定，再按骨架和最终网格定位镜头。需要原始 MMD 刚体/关节；收敛检查不能替代画面验收。
