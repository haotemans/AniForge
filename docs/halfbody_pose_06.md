## 已确定规格

| 项目 | 设计 |
| --- | --- |
| 编号 | 半身特色照 **06**（半身 01–04 为同一自然站姿的标准四视图） |
| Pose | **单手向镜头比耶（V 手势）**；另一手自然下垂或放在身体侧边 |
| 表情 | **开心笑脸**：双眼自然睁开并看镜头，嘴角明显上扬；可稍张嘴，不要求眨眼 |
| 身体 | 面向镜头，略微转身约 **10°–15°**；肩膀自然放松 |
| 头部 | 面向镜头，允许轻微歪头 **3°–8°**，避免夸张俯仰 |
| 镜头角 | **左右侧前方 15°**，按角色服装与手势遮挡情况选择左/右方向 |
| 镜头参数 | 透视相机、自然平视（默认俯仰/画面滚转 0°），以中焦为基础，避免近距离广角夸张透视 |
| 画幅与背景 | **3:4 竖幅，纯白 #FFFFFF** |
| 构图 | 头顶到大腿上部附近，保持头饰、头发、伸出的 V 手势完整入镜，尽量保留上半身服装及另一只手 |
| 输出 | 左右镜像是候选，**正式数据集只输出 1 张**，不将左右手扩展为多张 |

## 不同 MMD 模型的通用适配要求

1. **左右手均可使用**：同一 Pose 模板支持主动作左右镜像，并随镜头水平方向镜像；不是固定某个角色的左手或右手。
2. **按骨架与比例计算关节目标**：根据角色肩宽、上臂/前臂长度、腕部和指骨结构定位，不能直接复用参考图中的绝对坐标。可使用局部手型预设实现食指与中指伸展、其余手指自然弯曲。
3. **手势向镜头适度前伸**：V 手势应明显、完整、可辨，不能过于靠近相机造成巨大手掌或指尖被裁切；手掌不得遮住眼睛、鼻梁或嘴部主体。
4. **构图依据最终姿势**：计算最终变形后的头发、头饰、肩膀、肘部、双手与腰部包围范围；增加留白并确保手指完整入镜。复杂披风、长袖、武器或头饰不能强行套用固定裁切。
5. **实际映射优先**：表情形态键、指骨、手腕关节与骨架命名可能不同，缺失时退化为自然笑容或较保守的 V 手势，记录实际映射结果，不虚构成功状态。
6. **避免穿模与遮挡**：优先降低手臂抬举幅度、调整手势目标或人工微调；不要宣称已具备自动碰撞解决。
7. **与其他镜头区分**：半身 05 为单手叉腰/自信浅笑/±30°；半身 06 是**朝镜头前伸的单手比耶**/开心笑脸/±15°，与头部肖像的脸侧 Wink 比耶不同。
