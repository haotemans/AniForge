# AnimChar 动作与逐镜头工作流

AniForge 0.9.0 实施肖像 PR #1 和半身 PR #3–#10 的编排：肖像12、半身12、全身9、服装细节9，共42张。每个位置只生成一张正式图片；开发用正/侧/背不扩充正式数量。

## 安装

用户需单独拥有并安装 AnimChar Tools。已验证本机版本 `20261028035134`、Blender 5.2.2 LTS，接口包括原生图片姿势捕捉、文字动作生成、重定向与 Pose Editor。Updater ZIP 仅是更新器，完整插件由其官方分发提供，不包含在 AniForge 中。

本仓库提供可选的本地 ZIP 安装脚本：

```powershell
python tools/install_animchar.py --updater "用户提供的Updater.zip" --addon "用户下载的AnimCharTools.zip" --destination "Blender用户scripts/addons目录"
```

脚本验证 ZIP 路径，将已有安装备份到 `aniforge_addon_backups`，不处理 Key。启用 AnimChar Tools 后，在它自己的偏好设置填写 Key。AniForge 调用其账户服务，使用常规额度；参考图与骨骼数据交给该服务处理，模型网格与贴图不由 AniForge 上传。代码、导出预设和报告不包含 Key。客户端默认使用该插件已有的 HTTPS 接口。

## 一次完成一个动作

1. 打开 AniForge 的“镜头编排”，选择角色、肖像/半身、01–12中的一个位置。
2. 查看 PR 参考图与指定的机位、焦距、画幅、表情。标准四视图共用 AnimChar 的自然站姿；半身特色照按参考图捕捉；特色肖像可按已确认的动作语义调用 AnimChar 文字生成，或指定自己的参考图。
3. 配置 AnimChar 骨骼映射。身体及手指映射以当前 MMD 的实际名称为准；不直接把 Mixamo 局部四元数写进不同骨轴的 MMD。
4. 生成结果按当前骨架签名单独保存。相同图像/描述可复用捕捉缓存，只对新骨架重定向；若需另一结果，勾选“重新生成”。原生通用识别模型和姿势优化也可选择。
5. 需要编辑时，打开 AnimChar 标准角色的 Pose Editor，使用其原生身体/手指控制器和手型库。完成后由 AnimChar 重定向到当前 MMD。取消编辑恢复原角色，不修改源 PMX、贴图或角色骨架结构。
6. 点击“不出图预览”，检查手型、服装与镜头。开发三视图固定0°/90°/180°，局部检查裁切已有图片。每个动作逐一验收，不默认运行42张完整批次。

“待绑定”会阻止套用旧程序化动作。“已捕捉”不表示画面合格；可以记录待修说明，修好后标记“已验收”。已知待修镜头可单张预览，但阻止直接生成完整训练批次。表情缺失时按实际形态键回退，不把内部缓存名写入训练标签。

## 状态与模型适配

捕捉和重定向在隔离的骨架副本上进行。静态保存包含身体/手指及必要的祖先控制，保留捕捉的头部和手型。应用期间暂时停用这些骨骼上的 MMD IK/附加变换，避免第二次叠加；切换动作或渲染结束恢复骨骼、约束和原有物理设置。

Pose Editor 使用原生标准角色，是因为该构建的手型加载与部分控制器直接使用 Mixamo 名称/骨轴；不能声称其直接映射 MMD 编辑已可靠。编辑结果由原生重定向适配，原 MMD 数据不做改骨轴或重新绑定。宽袖、裙装、长发和饰品的碰撞仍需在真实模型上检查，AnimChar 生成成功不等于解决服装穿模。

预设 JSON 升级为 schema 3。旧半身9张的覆盖移入 `legacy_shot_overrides`，已有姿势仍保留供重新指定；不会把旧动作放入新增的标准四视图。新导入的 VPD 也不自动替换 PR 肖像/半身。全身和服装旧模板本次保留。

## 本地验证

锁暝已保存17份 AnimChar 静态动作：一份自然站姿、八份特色肖像、八份特色半身，覆盖24个照片位置。关节回放检查确认保存的结果来自原生重定向，渲染时不会再叠加旧手型角度。半身05原始/优化捕捉仍出现手部被衣服遮住或穿入的问题，记录为待修；其余动作未据此宣称视觉验收通过。

后台显式调用选定的 AnimChar 位置，可使用：

```powershell
blender --background character.blend --python tools/capture_animchar_plan.py -- --slots neutral half_body:5 --output D:/local-output --capture
```

此命令实际使用 AnimChar 账户额度，不渲染图片。`--general` 和 `--optimize` 对应其原生选项。生成结果、模型、测试场景和报告均留在本机，不进入 Git。

普通验证使用单元测试和无出图 Blender 测试；真实视觉检查另行显式运行 `tools/test_three_views.py --group half_body --plan-index 5`。已绑定的姿势按当前模型读取，缺少时不会以旧动作补齐。
