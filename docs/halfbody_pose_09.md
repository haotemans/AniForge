# 半身 09 · 单手轻触耳侧 / 甜美微笑 — 通用 Pose 参考

![半身 09 参考图](images/halfbody_09_pose_reference.webp)

> **视觉参考，不是动作资产。** 参考图中的人物、发型和服装仅为示例，不是 AniForge 的特定角色预设；本方案应适用于长发、短发、不同体型和不同 MMD 骨架。此图并不代表自动适配或碰撞检测已实现。

## 已确认的动作、表情和镜头

| 项目 | 设计规格 |
| --- | --- |
| 编号 | **半身 09**，属于规划中的八张特色半身照之一 |
| 核心 Pose | **单手轻触耳侧**，自然整理耳边发丝或做轻触耳侧动作；另一只手在身体侧边自然垂放 |
| 表情 | **甜美、柔和的微笑**：双眼自然睁开，目光看向镜头，嘴角轻微上扬 |
| 身体 | 自然侧身、双肩放松，避免大幅扭腰 |
| 头部 | 轻微转向镜头、可轻微歪头；不明显低头或仰头 |
| 镜头角度 | **左前或右前 55°**，平视（俯仰和画面倾斜默认 0°） |
| 镜头与焦段 | 透视中焦（约 70–85 mm），避免广角近距造成面部或抬起手臂变形 |
| 画幅 | **3:4 竖幅** |
| 背景 | **纯白 #FFFFFF** |
| 构图 | 头顶留白至大腿上部附近，耳边抬起的手、头饰、另一只手和腰部服装尽量完整入镜 |
| 正式输出 | 左右姿势与镜头各可作为候选，但 **只输出 1 张** |

## 通用 MMD Pose 的适配规则

1. **动作定义为“轻触耳侧”，而非“抓住发丝”。** 长发角色可以自然演绎整理头发；短发、束发或没有可操作发骨的角色只需要手指靠近耳侧，不能强制拉扯或移动原始发型。
2. **手臂与手掌按角色骨架比例定位。** 依据肩、肘、腕、头部与耳侧关键点计算自然弯曲方向；支持左右手镜像，不复制示例角色的骨骼坐标或绝对关节角。
3. **完整保留脸部识别信息。** 抬起的手不遮挡眼睛、鼻梁和嘴部，不与发束、头饰或耳饰产生明显穿模。对大型头饰、宽袖和装饰复杂的模型允许手动调整动作。
4. **动态镜头构图是后续实现目标。** 姿势应用后根据最终变形的头发、头饰、上肢、指尖与衣物边界调整相机距离，避免裁切；不声称现有插件已有自动避障或可见度评分。
5. **表情映射以实际模型能力为准。** 先使用模型支持的轻微笑容形态键；缺失则采用自然表情，真实记录是否应用成功。
6. **避免与半身其他动作重复。** 05 单手叉腰/自信浅笑/±30°；06 单手向镜头比耶/开心笑脸/±15°；07 双手腰前轻交叠/温柔浅笑/正面 0°；08 单手侧前方展开掌心向上/友好微笑/±45°；**09 单手耳侧轻触/甜美微笑/±55°**。

## 本次 PR 的实施边界

仅新增**这份设计规范和一张参考图**，不改动 Blender 的半身镜头总数、渲染逻辑或骨骼姿势实现。半身最终规划为 **四张标准四视图 + 八张不同动作 = 12 张**；其余镜头待逐张设计确认后统一实现与验证。
